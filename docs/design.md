# Il Calderone — design manifest

Direction **"La dispensa"** (the pantry shelf). This file is the style manifest: tokens, type, palette, spacing, components, screens, rules. Code follows it; when code and manifest disagree, fix one of them in the same commit. Other directions that were considered are in `../IDEAS.md`. The audit that fed it is `audit-1.md` (section B is mapped in "B items" below).

Phone first: design and check every screen at 390 px wide, then let it grow.

Build status and the gaps between this manifest and the code: `redesign.md`.

## 1. Idea

The app is a pantry shelf. Each dish stands on it as a specimen: its hand-drawn 8-bit icon (and, on the recipe page, its voxel model). Everything else is quiet, flat and made of the same unit as the icons: the **art-pixel** (4 px). Colour lives in the dishes and in data (the one primary action, status, today), not in chrome.

Identity that must survive any restyle:

- the 8-bit dish icons: 128×128 px PNG from a 32×32 grid, so 1 art-pixel = 4 px. Show them only at integer multiples of 32 px (96, 128, 160, 192, 256) with `image-rendering: pixelated`; never scale to fit a column;
- the voxel dish (`shared/dish-stage.ts`) as the recipe-page hero, on a flat field;
- Italian recipe names and units; vegan-leaning, calm, kitchen-practical.

## 2. Principles

1. **One motif.** The art-pixel sets spacing steps, radii and stepped corners. No second decorative language.
2. **Colour on data, not on chrome.** Surfaces are neutral green-grey. Saffron marks the one primary action per screen; basil marks links and "done"; danger marks destructive things.
3. **Flat.** No gradients, glow, glass, blur or resting shadows. Borders and tone steps separate things. (Shadow token exists and is `none` in these themes.)
4. **Nothing tiny.** Body 16 px, data labels 14 px, absolute minimum 12 px. Never use `opacity` to dim text; use `--muted`.
5. **Thumb first.** Targets ≥ 44×44 px, primary actions in the lower half, navigation at the bottom, margins 16 px.
6. **Meaning is never colour-only.** Today, done, error, selected each carry a word, icon or shape as well.
7. **Every state is designed:** empty, loading, error, offline, long German text.
8. **Tokens only.** No colour, size or radius literal in component CSS.

Banned (house rules from the design skill): gradients, glow, glass, rest shadows, eyebrows (small caps labels above headings), index numbering ("01"), thin rule ornaments, monospace (except file names), emoji as UI (decorative only, `aria-hidden`), cream + terracotta, violet/indigo accents, more than two typefaces.

**Dark is a colour-only variant**: same layout, type, spacing and components; only tokens change. True neutral greys (no blue/navy cast); saffron stays the action colour.

**The original Calderone themes** (`calderone-light`, `calderone-dark`: cream + terracotta) and the 15 community themes stay selectable in Account → Appearance. They provide the original token set only: the new tokens (`--primary`, `--primary-text`, `--line-strong`, `--placeholder`) are derived for them in `tools/make_themes.py` (primary = accent, line-strong = muted mix, placeholder = muted), so every theme still passes the gate.

### Dish colours (reference, from the icons)

For art direction, not tokens: saffron/pumpkin `#F0B030`, flour `#F0F0D0`, herb green `#509030`, aubergine `#705070`, indigo-slate `#303050`, blue `#3070B0`, terracotta-brown `#905030`, ceramic grey `#B0B0B0`. ## 4. Type

Fonts are bundled by `@fontsource` (listed in `web/angular.json`), no CDN.

| Role | Family | Token | Used for |
|---|---|---|---|
| UI + titles | Bricolage Grotesque Variable | `--font` / `--font-title` | headings, buttons, labels, navigation |
| Reading | Literata Variable | `--font-read` | ingredients, steps, notes (long text) |
| Figures | Bricolage Grotesque, 800, `tabular-nums` | `--font-figure` | timer digits, quantities in cooking mode, servings, step numbers. A pixel face (Pixelify Sans) was tried and dropped: its 5 reads as S and its 9 as 8 at timer sizes |

Stack tails: `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif` / `Georgia, serif` / `monospace`.

Scale (rem on a 16 px root; only these five):

| Token | Size / line | Use |
|---|---|---|
| `--t-xs` | 12 px / 16 | source lines, badges, file names. Floor: nothing smaller |
| `--t-sm` | 14 px / 20 | data labels, meta lines, chips, table cells |
| `--t-md` | 16 px / 24 | body, inputs (16 px also prevents iOS zoom), buttons |
| `--t-lg` | 22 px / 28 | section titles, current step in cooking mode (20 px Literata) |
| `--t-xl` | 30 px / 34 | page and recipe titles |

Weights: 400 body, 600 UI emphasis, 800 titles (Bricolage). Titles may wrap to three lines; never clamp card titles. Numbers in lists use `font-variant-numeric: tabular-nums`. Long German compounds: `overflow-wrap: anywhere; hyphens: auto` on user-supplied text.

## 5. Space, shape, motion

- **Unit:** the art-pixel, `--px: 4px`. Spacing steps: 4, 8, 12, 16, 24, 32, 48 (`--s-1`…`--s-7`). Page margin 16 px; gap between tiles 12 px; section gap 24 px.
- **Radius:** `--r-1: 4px` (inputs, chips), `--r-2: 8px` (tiles, sheets). Buttons and chips may use a **stepped corner** (a 4 px notch drawn with a `clip-path` polygon or a two-step border) as the pixel signature; never a full pill except the timer chip and the servings stepper.
- **Borders:** 1 px `--line` for dividers, 2 px `--line-strong` for controls and the focus ring `outline: 3px solid var(--accent); outline-offset: 2px` (also on tinted fields; check contrast).
- **Targets:** minimum 44×44 px (`--hit: 2.75rem`), 56 px for shopping rows and cooking-mode controls, 8 px between neighbours.
- **Motion:** 150 ms ease-out for state changes only (sheet slide, chip toggle); respect `prefers-reduced-motion` (no transform animation, no pulse). Timer ringing pulses via background step, not scale.
- **Z-index:** content 0, sticky header 10, timer strip 30, bottom tab bar 40, sheet/dialog 60, toast 70.
- **Safe areas:** `viewport-fit=cover`; the tab bar, sheets and the timer strip add `env(safe-area-inset-bottom)`.
- **Hover** styles only inside `@media (hover: hover)`.

## 6. Components

- **Tab bar (bottom).** Four labelled destinations: Rezepte, Menü, Einkauf, Mehr. Label always visible (14 px), icon above (line icon from `shared/nav-icon.ts`, 24 px), selected = `--accent` text and a 4 px bar on top of the item, `aria-current="page"`. "Mehr" opens a bottom sheet with Kollektionen, Tagebuch, Haushalte, Admin, Account, language, logout. Height kept in `--nav-h`; anything fixed above it uses `bottom: calc(var(--nav-h) + env(safe-area-inset-bottom))`.
- **Top bar.** Brand (weekly logo, left) and nothing else on a phone; page title is an `<h1>` in the page, not a bar. Max 56 px.
- **Recipe card.** `--surface` tile, dish icon 160 px (integer scale, `pixelated`), full title 16 px / 600 below, one 14 px meta line (time · diet). The "add to menu" action is a 44 px button in a row under the title, never over the picture. Two columns at 390 px, three from 640 px.
- **Buttons.** Primary: `--primary` fill, `--primary-text`, 44 px high, one per screen. Secondary: 2 px `--line-strong` outline, `--text`. Tertiary/link: `--accent` text, underline, 44 px hit area. Destructive: `--danger` outline, filled `--danger`/`--on-danger` only inside the confirm sheet.
- **Chips / filters.** 14 px, 44 px hit area (visual 32 px + padding), selected = `--accent-soft` fill + `--accent` text + a check glyph. Filters collapse into one "Filter" row that opens a sheet; applied filters show as removable chips ("Filter entfernen: Vegan").
- **Stepper (servings).** Pill with − / value / +, 44 px buttons, value in `--font-figure`.
- **Fields.** `--surface-2` fill, 2 px `--line-strong` border, 16 px text, label above (14 px / 600), `--placeholder` colour, required marker `*` (`aria-hidden`) plus `aria-required`. Errors are inline under the field: 14 px `--danger` with an icon, `aria-invalid="true"`, `aria-describedby`, focus moves to the first invalid field; a toast is only a summary.
- **Sheet (bottom dialog).** `<dialog class="sheet">`, slides from the bottom, `--surface`, top corners `--r-2`, grabber 32×4 px, `overscroll-behavior: contain`, safe-area padding, close on backdrop and Escape. Replaces every native `confirm()`/`prompt()`.
- **Confirm + undo.** Destructive actions ask once in a sheet (title names the object, the destructive button says what it does: "Rezept löschen"). Where reversible, skip the sheet and show an **undo toast** for 8 s instead.
- **Toast.** Above the timer strip and tab bar; 14 px; `role="status"`, errors `role="alert"`; never the only error channel.
- **Timer strip.** Replaces the right-edge tab. A bar above the tab bar showing running timers as 44 px chips (bold tabular digits, pause label + label for paused, word "Fertig" when ringing, pulse by background step). Tap = pause/resume, trailing "+" opens the duration wheel. Hidden when no timer runs. Ringing sets `role="alert"`.
- **Shopping row.** 56 px minimum, two lines: name + amount (amount `white-space: nowrap`, tabular), second line 12 px source. Check target is the whole row. "Always at home" and "move to household" live in the row's "…" sheet, not as extra lines.
- **Menu day row.** Day name + date, dish icon 96 px, dish title, servings. **Today** = the word "Heute"/"Oggi" in a badge plus a 4 px leading bar (never colour alone).
- **Empty / loading / error.** Empty: the dish icon of the section at 128 px, one sentence, one action. Loading: static skeleton tiles in `--surface-2` (no shimmer). Error: sentence + "Retry", inline.
- **Badges.** 12 px / 600, `--surface-2`, 4 px radius, text + optional glyph.

## 7. Screens

Each screen at 390 px, in order of vertical position.

1. **Recipe list.** Search field (sticky, 44 px) · "Filter" row · two-column cards · "+" new recipe as a secondary button at the end of the list (no floating button). 
2. **Recipe page.** Voxel dish on a flat `--surface` field (4:3, picture crossfade stays) · title (30 px) · one meta line · two buttons: **Cucina** (primary) and **Aggiungi** (secondary) · "Dettagli" disclosure (facets, tags, visibility, edit, variant, download, history, delete in a "…" sheet) · ingredients (two columns: name / qty+unit; servings stepper in the heading row) · steps as a real `<ol>`, Literata 17/26 · notes · source line (12 px).
3. **Cooking mode ("Cucina").** See section 8.
4. **Menu.** Week switcher (segmented, 44 px) · seven day rows · today marked with word and bar · empty slot = row with "+" (44 px) instead of a dashed box.
5. **Shopping list.** Space switcher · week · rows by section · done rows move to a collapsed "Erledigt (n)" group with count · extras field at the bottom.
6. **Editor.** One column. Controls stack: row = name (full width) / qty + unit / note / tools. Step title full width. Sticky save bar above the tab bar. Leaving with unsaved changes asks in a sheet.

## 8. Cooking mode ("Cucina")

Goal: while cooking you do not care about tags, buttons or the 3D image; you want **ingredients, steps and timers**, with the previous and next step in sight. It is *not* a one-step-at-a-time wizard.

Entry: the primary button **Cucina** on the recipe page. State lives in the route/query (`?cucina=1`), so Back leaves it. Servings carry over.

Layout, top to bottom (390 px):

1. **Header** (sticky, 56 px): back arrow, recipe title (single line, ellipsis), servings stepper.
2. **Ingredients band** (sticky under the header): collapsed it is a 44 px row "Zutaten (8) ▾"; expanded it is a compact two-column list (name left, quantity + unit in bold tabular figures), max 40 % of the viewport height, scrolls inside. Tap a row to tick it off (strike + `--muted`, local only); servings rescale quantities in place.
3. **Steps**, all visible in one scroll (`<ol>`):
   - **current**: Literata 20 px / 30, 4 px `--primary` bar on the left, title in 600, full text, an inline **Timer mm:ss** button (44 px) per duration found in the text;
   - **previous** and **next**: normal 16 px, full text, `--text` colour;
   - **others**: 16 px, `--muted` (never opacity), collapsed to the first two lines with "mehr";
   - tapping any step makes it current; the current step is kept in `sessionStorage`.
4. **Primary bar** (fixed, above the timer strip and the tab bar): "Weiter" (primary, full width, 56 px) and a "Zurück" text button. Last step: "Fertig".
5. **Timer strip** (shared, section 6) above the tab bar with the running timers.

Hidden in cooking mode: voxel dish, facets, tags, visibility, the action buttons, notes (reachable via "Notizen" at the end), file name, variants.

Rules: the screen stays awake (Screen Wake Lock, feature-detected, released on leave or when the page is hidden); tap targets 56 px; text min 16 px; works in both light and dark (dark is the "kitchen at night" setting); no animation except the timer ring; German strings must not clip at 390 px; everything reachable with one thumb.

## 9. Themes

- `tools/make_themes.py` is the only place where theme CSS comes from. A theme = bg, surface, surface-2, line, line-strong, text, muted, accent, primary, ok, danger (+ derived). The gate nudges any text colour until it reaches 4.5:1 on every background it is drawn on (see `PAIRS`) and records nudges in the file header; `line-strong` must reach 3:1 on bg and surface.
- Default light = `dispensa-light`, default dark = `dispensa-dark` (`themes.ts`). Auto mode follows `prefers-color-scheme`. Saved choices keep working.
- To add a theme: add it to the script, run `python tools/make_themes.py`, run `pytest tests/test_themes.py`.
- `<meta name="theme-color">` follows the active theme's `--bg` (set in `core/theme.ts` and the inline script in `index.html`).

## 10. Accessibility checklist (per screen)

- Every control has a name; repeated controls name their target ("Zutat entfernen: Mehl").
- Targets ≥ 44 px; text ≥ 12 px; body 16 px; no horizontal page scroll at 390 px in de/fr.
- Contrast: text 4.5:1, control borders and icons 3:1, focus ring 3:1.
- Focus visible, logical order, focus returned after sheets close and after row add/remove.
- Today/done/error/selected have a non-colour cue.
- Landmarks: skip link, `<main id="main" tabindex="-1">`, labelled `<nav>`.
- Reduced motion respected; timers announce when ringing.
- Forms: visible label, inline error, `aria-invalid`, `autocomplete`/`autocapitalize` set, 16 px inputs.
- URL carries view state (`?space=&week=`, `?cucina=1`) so Back and reload work.

## 11. Do / Don't

| Do | Don't |
|---|---|
| Show icons at 96/128/160/192/256 px | Stretch icons to fill a column or use smooth scaling |
| One saffron primary button per screen | Saffron on chips, links, icons and headings at once |
| Dim with `--muted` | Dim with `opacity` |
| Mark today with a word and a bar | Mark today with colour alone |
| Put "add" under the title | Float buttons over pictures |
| Bottom sheet for confirms, undo toast when reversible | `confirm()`/`prompt()` |
| Inline errors with `aria-invalid` | Toast-only errors |
| Use tokens | Hard-code colours, sizes, radii |
| Let German text wrap | Clip, clamp or abbreviate titles |
| Keep 16 px inputs | Inputs under 16 px (iOS zoom) |

## 13. Reusing this style elsewhere

Copy: the token table (§3) and `tools/make_themes.py`'s gate; the scale (§4) and space/shape rules (§5); the component list (§6). Replace: the dish icons by the new product's own pixel-grid pictures (keep the integer-scale rule), the saffron primary by the product's one action colour (keep ≥ 4.5:1 for its text). Keep the banned list in §2: it is what stops the result from looking generic.
