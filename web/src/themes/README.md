# Colour themes

Each theme is one CSS file, `<pack>/<variant>.css`. It sets Il Calderone's colour tokens on `[data-theme="<pack>-<variant>"]`.
- The app puts the active theme on `<html data-theme="…">`.
- The theme picker reuses the same attribute on each preview card, so every card shows its theme's own colours.
- Users choose a favourite **light** theme and a favourite **dark** theme in *Account → Appearance*. In *Automatic*
  mode the site follows the phone's light/dark setting (`prefers-color-scheme`).
  - The choice is saved in the browser (`localStorage["calderone.theme"]`) and in the account.
  - An inline script in `index.html` applies it before the first paint.

## The tokens
| Token | Used for |
|---|---|
| `--bg` | page background |
| `--surface` | cards |
| `--surface-2` | buttons, chips |
| `--line` | borders |
| `--text`, `--muted` | text, secondary text |
| `--accent` | links and primary buttons |
| `--accent-text` | text on accent |
| `--accent-soft` | soft accent background |
| `--ok`, `--danger` | success and error colours |
| `--on-danger` | text on danger |
| `--shadow` | card shadow |
| `--backdrop` | behind dialogs |
| `color-scheme` | light or dark form controls and scrollbars |

## Adding or changing a theme
**Don't edit the CSS files by hand.** They, `index.css` and `themes.ts` (the list the app shows) are generated by
`tools/make_themes.py`.
1. Add or change the palette in `tools/make_themes.py`, mapping it onto the tokens like the existing ones.
2. Run `python tools/make_themes.py`. It writes the files and prints a contrast report.
   - **Readability rule:** every theme must reach WCAG AA contrast, 4.5:1, for text, secondary text, links,
     success/error text and text on buttons, against the page and the cards.
   - A palette colour that is too faint is darkened (light themes) or lightened (dark themes) just enough, keeping its
     hue. The change is noted in the file's header comment.
3. Rebuild (`cd web && npm run build`) and look at it on a phone.

## The title image (logo), per theme and per week
The "Il Calderone" title in the top bar (`app/shared/brand.ts`) is an image from `web/public/logos/`:
```
web/public/logos/
  light/   light-coloured logos → shown on DARK themes
  dark/    dark logos           → shown on LIGHT themes
  medium/  logos that suit any theme → added to both
```
- Any PNG, JPG, WebP, AVIF, SVG or GIF works. A wide, short image fits best (e.g. 610×78); the box is 40 px high.
- `scripts/logos.mjs` lists the files into `logos/logos.json`. It runs on `npm run build`, `npm start` and
  `./deploy.sh`, so adding a logo = drop the file into the folder and rebuild.
- **Which one:** `core/logo.ts` counts weeks continuously (Monday–Sunday), not by week of the year, which restarts at 1
  every January.
  - The images are dealt in cycles of N weeks (N = the images for that kind of theme, medium ones included), shuffled with a random generator seeded by
    the cycle number.
  - Every logo shows once before any repeats, never two weeks in a row, and every phone shows the same one all week.
- **Fallbacks:** an empty folder, or an image that fails to load, shows the text title.
